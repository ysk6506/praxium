# ADR-0042 웹 UI의 접속 방식 표시, URL에 담는 상태, 오류 표시, 표시 이름 사전

## 맥락

릴리스 실행 파일의 독립 검증에서 웹 UI의 결함이 나왔다. 같은 탭에 새 데모 링크를 붙여 넣어도 접속되지 않고(주소의 `#`만 바뀌면 페이지가 다시 로드되지 않는다), 인증 오류가 데모 사용자가 한 적 없는 "서버를 시작할 때 지정한 토큰"을 말하고, 오류에 원인이 없고, 페이지 위치와 검색어가 주소에 없어 뒤로 가기와 새로 고침이 상태를 잃고, 영어 원시 값이 한국어 화면에 섞인다. 서버는 로컬 모드 접속 링크(`#/connect?token=…&mode=local`)를 내기로 했다.

## 결정

1. **접속 방식 셋.** 데모(`demo=1`), 로컬 모드(`mode=local`), 직접 입력한 개발용 토큰. 접속 표시는 토큰에 묶어 저장하고(데모는 `praxium.demo-token`, 로컬은 `praxium.local-token`), 진입 정보는 `data/entry.ts` 한 곳이 관리한다. 다른 토큰을 입력하거나 토큰을 지우면 두 표시를 함께 지운다. 로컬 모드이면 데모 배너 대신 "로컬 모드: 이 컴퓨터에서 혼자 쓰는 용도이며 운영용이 아닙니다"와 "로컬" 배지를 보인다.
2. **실행 중에도 접속 링크를 받는다.** `main.tsx`가 첫 로드의 `applyEntry`에 더해 `hashchange`마다 같은 함수를 부른다(`watchEntry`). 주소와 표시를 먼저 바꾸고 토큰을 나중에 알려, 토큰을 듣는 쪽은 이미 새 주소를 본다. 화면은 토큰을 키로 다시 만들고 조회 훅은 토큰이 바뀌면 이전 데이터를 버린다.
3. **인증 오류의 문구는 접속 방식을 따른다.** 데모와 로컬 모드는 "서버를 다시 시작하면 접속 링크가 바뀝니다. 터미널에 출력된 새 주소를 여십시오.", 직접 입력은 기존 안내. 접속 설정 화면은 세 방식을 설명한다.
4. **오류에 원인을 싣는다.** 서버가 `params`에 싣는 키(`message`, `field`, 404의 `resource`와 `id`)를 화면이 읽는다. 필드와 메시지는 바로 보이고, 코드, HTTP 상태, 추적 ID와 나머지 값은 "자세히"에 접는다. 찾을 수 없다는 오류는 서버가 보낸 값(없으면 화면이 아는 KG 이름, 객체 ID, 타입 이름)을 문구에 넣는다. 서버에서 `params`의 새 키가 없으면(오래된 서버) 기존 문구를 쓴다.
5. **URL에 담는 상태.** 해시의 쿼리에 담는다: 객체 테이블은 `page`, `cursor`, `size`, `cols`, 타입 목록은 `q`, `all=1`, `sort`, `dir`. 기본값은 쓰지 않는다. 페이지 이동은 새 기록 항목을 만들고(뒤로 가기), 검색어와 컬럼 선택은 주소를 바꿔 쓴다. 커서는 앞으로만 가므로 이전 페이지의 커서는 탭의 `sessionStorage`에 두고, 없으면(링크 공유) "이전"은 꺼지고 "처음"이 있다. 라우터는 `Route`의 모양을 바꾸지 않고 쿼리를 읽는 훅(`useHashParams`)을 더했다.
6. **화면 이동의 스크롤.** 링크나 버튼으로 다른 화면에 가면 맨 위, 뒤로·앞으로는 그 화면의 이전 위치(내용이 늦게 차므로 높이가 모자라면 다시 시도한다). 쿼리만 바뀌면 위치를 유지한다.
7. **모르는 주소.** `resolveRoute`가 모르는 경로를 `notFound`로 알린다(`parseRoute`의 너그러운 읽기는 그대로 둔다). 모르는 `tab`은 기본 탭으로 가고 주소를 고쳐 쓴다.
8. **표시 이름 사전.** `data/display.ts` 한 곳에 제품이 정한 닫힌 값의 한국어 이름을 둔다: 계층, 근거 등급과 종류, 신선도, KG의 상태와 역할, 링크 방향. 원래 값은 툴팁이다. 속성 이름과 값, 타입 이름은 모델의 데이터이므로 영어 그대로 두고, 표준 모델에 한국어 표시 이름이 생기면 그때 쓴다.
9. **문구와 화면.** "N쪽"을 "N페이지"로, 타입 수는 "168개 타입 중 객체가 있는 67개"로, 이웃은 불러온 수와 전체 수를 함께, KG 목록은 별칭과 이름을 나눠 쓴다. 본문으로 건너뛰기, 좁은 폭의 접히는 메뉴, 타입 목록의 컬럼 정렬, 테이블과 같은 순서의 컬럼 선택, 넓은 테이블의 가로 스크롤 단서를 더한다.
10. **구조.** 새 유닛과 의존성이 없다. Base UI는 `ui`에서만, 색은 토큰 파일에서만 쓴다.

## 이유

- 같은 탭에 링크를 붙여 넣는 일은 데모를 다시 시작할 때마다 일어난다. 새로 고침을 요구하면 처음 쓰는 사람이 막힌다.
- 접속 방식을 알아야 오류 문구가 맞는다. 데모 사용자에게 토큰을 입력하라고 하면 할 수 있는 일이 없다.
- 뒤로 가기와 링크 공유는 브라우저가 이미 하는 일이다. 상태를 주소에 두면 별도 장치 없이 된다.
- 계약에 없는 서버 정보(데모인지)는 지금처럼 링크의 프래그먼트로 알린다(ADR-0038).

## 대안과 기각 사유

- **라우터와 상태 관리 라이브러리.** ADR-0035가 쓰지 않기로 했다. 작은 훅 둘로 된다.
- **페이지 번호만 주소에 담기.** 커서 방식이라 번호만으로는 그 페이지를 열 수 없다.
- **모든 이전 커서를 주소에 담기.** 커서가 130자쯤이라 페이지가 늘수록 주소가 길어진다.
- **새로 고침을 안내하기.** 문제를 사용자에게 넘긴다.

## 결과

- 서버가 로컬 모드 링크를 내면 바로 쓸 수 있다. 서버가 `params`의 새 키를 채우면 오류 화면이 그 값을 쓴다.
- 새로 고침한 뒤 3페이지 이상의 "이전"은 탭에 저장된 커서가 있을 때만 켜진다.
