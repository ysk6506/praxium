# ADR-0008 현실 데이터 받기: 어댑터와 프리셋, 여덟 단계, 원본 기록, 닫힌 정제, 읽기 전용 세 겹, 안전장치, 브랜치

## 맥락
제품 책임자는 지금 E2E 프로세스가 아니라 데이터 연결부터 KG를 만들고 운영하는 일을 구체화하라고 했다(ADR-0005). 이 결정은 그중 "현실 데이터를 받아 KG의 새 버전까지 가는 길"이다.

테라리움은 이 길을 이미 설계했다(T0144, T0149~T0152, T0161, T0164~T0166). 그러나 그 설계는 이틀 안에, 요구가 하나 올 때마다 고쳐 가며 쓰였고 한 번도 재거나 실제 소스와 대조되지 않았다. 그래서 틀을 이어받되 하나씩 다시 정한다. 쓰는 조직은 작은 팀이 아니므로 소스도 고치는 사람도 많다고 놓고 정한다.

넘겨받은 것 문서 6절의 쟁점 가~아는 E2E 프로세스와 테라리움과의 이음매에 관한 물음이라 이 결정이 직접 답하는 것은 없다. 가장 가까운 것은 바(운영 경로가 되면 멈추면 안 된다)이고, 동기화가 멈춰도 마지막 KG 버전이 남는 것(결정 9, ADR-0011)으로만 닿는다. 이 결정은 그 위에서 일이 돌 기반이다.

## 결정
1. **소스의 역할은 지금 구성 하나다.** KG를 만드는 데이터(무엇이 있고 어떻게 이어졌나)만 받는다. 실시간 상태(온도, 전력, 알람의 현재 값)는 미룬다. 넘겨받은 "사건"과 "실측" 역할은 시뮬레이터의 재현과 보정용이었으므로 가져오지 않는다.
2. **어댑터와 프리셋.** **어댑터**는 프로토콜 하나를 말하는, 제품에 들어 있는 소수의 코드다. **프리셋**은 소스 제품 하나에 맞춘 데이터다(허용된 요청의 목록과 기본 매핑).
   - 첫 어댑터 셋: 파일(엑셀, CSV 올리기) / HTTP JSON(세션 인증, 쪽 넘김, 선언한 요청 틀) / 읽기 전용 SQL.
   - **수집 봉투는 정식 확장 지점이다.** 제품이 모르는 소스는 맡은 조직이 자기 수집기를 만들어 공개된 수집 봉투(무엇을, 언제, 온전히 받았는지, 기록들)로 보낸다. 닿지 못하는 망의 소스도 이 길로 받는다. 받은 뒤는 다른 소스와 같다. 봉투의 형식은 계약 단위가 쥐고 버전이 있다.
   - 선언만으로 되는 것은 단순한 요청까지다. 세션과 호출 한도가 까다롭거나, 검색 작업을 걸고 결과를 받아야 하거나, 장비를 순회해야 하는 소스는 어댑터가 따로 필요하고, 결정 기록과 함께 하나씩 더한다. 모든 소스가 셋으로 된다고 약속하지 않는다.
   - 프리셋은 지어낸 견본으로 도는 시험이 있어야 실린다. 사용자가 코드를 넣는 길은 없다.
3. **동기화 한 번은 여덟 단계다.** 수집 / 정제 / 매핑 / 식별과 병합 / 링크 / 차이 / 안전장치 / 적용. 수집은 접속을 알고 모델을 모른다. 정제는 데이터셋만 안다. 매핑은 모델을 알고 접속을 모른다. 식별과 병합은 모델과 식별 이력을 안다. 연결 확인은 단계가 아니라 필요할 때 하는 점검이다. 연동과 모델 동기화의 경계는 수집과 그 뒤다.
4. **원본 기록**은 기록 단위로, 받은 모양 그대로(JSON) 보관하고 고치지 않는다. 같은 기록이 다음 수집에서도 그대로면 복제하지 않고 "처음 본 수집 ~ 마지막으로 본 수집"의 구간만 늘린다. 내용 해시가 있다. 받을 때 비밀 값과 가릴 필드를 지운다(프리셋이 선언). 보관 기한을 둔다. 받아 둔 원본 기록만으로 뒤 단계를 언제든 다시 돌릴 수 있다.
5. **정제의 연산은 닫힌 목록 열넷이다.** 행으로 펼치기 / 컬럼으로 모으기(피벗) / 컬럼 나누기 / 조인 / 유니언 / 고르기(필터) / 빈 값 채우기 / 값 바꾸기 / 컬럼 고르기와 이름 바꾸기 / 자료형으로 읽기(날짜, 수, 단위) / 겹친 행 없애기 / 표에서 찾아 바꾸기 / 정규식으로 뽑기 / 이어 붙이기. "값 바꾸기"가 쓰는 함수는 검토를 거쳐 제품에 들어 있는 순수 함수의 목록에서 고른다. 새 연산은 결정 기록으로 더한다.
6. **매핑과 링크 정의는 층이 따로다.** 매핑은 데이터셋의 컬럼을 객체 타입의 속성과 식별 키에 잇는다. 링크 정의는 링크 타입마다 "어떤 조건이면 잇는다"를 적는다. 사람이 선을 긋지 않는다. 조건의 종류는 닫힌 목록 여섯이다: 다듬은 키가 같다 / 목록에 들어 있다 / 범위에 든다(주소가 대역에) / 자리가 맞는다(랙과 칸) / 부모가 같다 / 다른 링크를 따라간 끝이 같다.
7. **읽기 전용은 세 겹이다.** 읽기 메서드만 허용하는 것은 지킬 수 없다(로그인, 검색 실행, GraphQL은 읽기인데도 POST를 쓴다).
   - 첫째, 프리셋의 **요청 허용 목록**: (메서드, 경로의 틀, 본문의 모양) 단위. 목록 밖의 요청은 만들어지지 않는다.
   - 둘째, **소스 쪽 계정이 읽기 전용**이다. 연결할 때 관리자가 확인하고, 어댑터가 확인할 수 있는 소스에서는 권한을 점검한다. SQL은 조회만 되는 역할을 쓴다(읽기 전용 트랜잭션 설정은 경계가 아니다).
   - 셋째, **어댑터의 포트에 쓰는 메서드가 없다.** 구조 검사가 본다.
   - 쿼리 말을 받는 소스에서 검색은 관리자가 자유롭게 적는다. 저장할 때 **허용된 명령의 목록**으로 검사한다(차단 목록이 아니다).
8. **소스를 지킨다.** 소스마다 동시 요청 상한(기본 1), 속도 상한, 물러났다 다시 하기, 잇달아 실패하면 끊기(인증 실패는 바로 끊는다: 계정이 잠기지 않게), 받아도 되는 시간대. 비밀 값은 바깥 비밀 저장소를 가리키는 참조만 저장한다(비밀 값 제공자는 포트 뒤).
9. **안전장치는 자동 적용 전에 멈추는 검사다.** 숫자는 모두 기본값이고 **재지 않은 가정**이다.
   - 덜 받은 수집은 뒤로 가지 않는다. 쪽 넘김이 끝까지 갔는지, 소스가 알려 준 수와 맞는지, 지난번보다 기록 수가 크게 줄지 않았는지를 수집 단계에서 본다.
   - 같으면 새 버전을 만들지 않는다. 처음 적용과 정의를 고친 뒤 첫 적용은 사람이 차이를 보고 확인한다. 받은 모양(컬럼, 자료형)이 바뀌면 멈춘다.
   - 객체가 한 번에 많이 사라지면 멈춘다. 비율과 건수를 함께 본다(가정: 10% 이상이면서 5건 이상, 또는 500건 이상).
   - 안 보이는 것은 바로 지우지 않는다. 온전한 수집에서 잇달아 안 보이면(가정: 3번) 물러난 것으로 표시하고, 물러난 객체는 이력에 남는다.
10. **수 맞춤(행 회계)을 다시 정의한다.** 원본 기록 하나는 끝에 넷 중 하나로 분류된다: **쓰임**(객체나 링크 하나 이상에 기여) / **규칙이 걸러 냄**(어느 규칙인지) / **문제**(어느 문제인지) / **안 쓰임**. 넷의 합은 받은 수와 같다. 단계마다 들어온 수 = 나간 수 + 떨어진 수(이유와 함께)가 맞아야 한다.
11. **출처 따라가기.** 객체와 링크는 원본 기록의 참조와 규칙의 버전을 가진다. 값 하나의 근거는 같은 규칙을 다시 돌려 그때 보여 준다. 값마다 출처를 통째로 저장하지 않는다.
12. **정의의 버전과 브랜치.** 정의(소스 설정, 프리셋, 정제, 매핑, 식별 규칙과 예외 목록, 링크 정의, 안전장치의 값, 타입 등록부)는 바뀌지 않는 버전으로 쌓이고, 낱개의 항목마다 주인 도메인이 있다.
    - **브랜치**는 여럿이 동시에 열 수 있다. 고치면 **후보 실행**으로, 받아 둔 원본 기록에서 후보 KG를 만들어(소스에 다시 가지 않는다) 운영의 지금 버전과 차이(정의와 KG)를 본다.
    - **병합**은 고친 사람이 아닌 사람이 항목의 주인 도메인에서 승인한다. 병합 직전에 운영의 최신 정의 위에서 후보 실행을 다시 하고 같은 안전장치를 거친다. 같은 항목을 두 브랜치가 고쳤으면 늦은 쪽이 멈추고 사람이 고른다.
    - 되돌리기는 이전 정의를 새 버전으로 다시 병합하는 것이다. 정의는 글로 된 형식으로, 정해진 순서로 내보내고 들일 수 있다.
13. **엑셀**은 위치·전원·냉방의 주된 길이다. 양식을 주고 양식대로면 매핑 없이 받는다. 한 줄에 장비 하나인 목록 형식을 받는다. 격자 모양의 실장도는 읽지 않고 목록 양식을 안내한다. 파서는 포트 뒤에 두고 버전을 고정한다. 파일의 크기와 압축 푼 크기에 상한을 두고 수식은 값으로만 읽는다.
14. **일정과 기록.** 소스마다 주기(손으로만, 간격, 정해진 시각). 동기화 한 번은 기록 하나이고 단계마다 수와 시간을 남긴다. 지표를 밖에서 읽을 수 있게 낸다. 로그에는 실행·소스·단계의 이름표와 수만 찍고 비밀 값과 행의 내용은 찍지 않는다.
15. **시험 자료.** 지어낸 세계 하나에서 여러 소스의 모양(엑셀, HTTP JSON, SQL)을 뽑아내는 생성기를 둔다. 소스 사이의 키가 맞물리고 정답 KG가 생긴다. 흩뜨리는 장치(모양 바뀜, 덜 받음, 대량 사라짐, 합친 셀, 수식)로 안전장치를 시험한다. 실제 데이터는 저장소에 두지 않는다.

## 이유
넘겨받은 설계에서 무엇을 그대로 두고 무엇을 바꿨는지는 아래와 같다. 근거는 조사 보고서에서 확인한 것만 적었다.

| 넘겨받은 것 | 이 결정 | 까닭 |
|---|---|---|
| 소스의 역할 셋: 구성, 사건, 실측 (T0149) | 구성 하나만 (1) | 사건과 실측은 시뮬레이터의 재현과 보정용이었다 |
| 범용 커넥터 넷과 프리셋 (T0144) | 어댑터 셋과 프리셋, 푸시는 수집 봉투 (2) | 선언만으로는 세션, 검색 작업, 순회를 못 담는다. 수집 봉투는 마지막 길이 아니라 정식 길이다 |
| 읽기 전용 세 겹, 셋째는 GET만 (T0149) | 세 겹의 틀은 그대로, 내용을 고침 (7) | 읽는 POST가 있어 "GET만"은 거짓 보증이다. 요청 단위 허용 목록, 읽기 전용 계정, 쓰는 메서드 없음으로 바꿨다 |
| 쿼리 말 소스는 위험 명령 차단 목록 (T0152) | 허용된 명령의 목록 (7) | 차단 목록은 모르는 명령을 통과시킨다 |
| 네 단: 연결, 수집, 대응, 적용 (T0144) | 여덟 단계 (3) | 식별과 병합이 없었다. 변환과 식별을 가른 제품 사례가 있다 |
| 정제, 매핑, 링크 정의를 층으로 나눔 (T0165) | 그대로 (6) | 제품 책임자의 요구다 |
| 정제 연산 여덟 (T0161) | 열넷 (5) | 여덟으로는 모자란다는 추정. 이름은 현업의 말(T0167)을 쓴다 |
| 링크 조건 유형 다섯 | 여섯 (6) | 키 일치, 위치, 연결 목록, 그룹, 기본 규칙을 다시 짰다. 모르는 것을 가정으로 메우지 않는다(ADR-0007) |
| 행 회계: 받은 행 = 객체 + 링크 + 문제 + 안 쓰인 행 (T0161) | 원본 기록 단위의 넷 분류 (10) | 한 행이 객체도 링크도 되는 경우와 펼치기·조인 뒤의 기준이 없었다 |
| 안전장치 표 (T0151) | 틀은 그대로, 셋을 고침 (9) | 덜 받은 수집을 수집 단계에서 막고, 10% 단독을 비율과 건수로 바꾸고, "삭제"를 "물러남 표시"로 바꿨다 |
| 값마다 속성 출처 한 줄 | 규칙을 다시 돌려 보여 줌 (11) | 수천만 규모에서 저장이 감당되지 않는다 |
| 브랜치 (T0166) | 후보 실행, 같은 안전장치, 항목 단위 부딪침, 되돌리기는 다시 병합 (12)은 그대로 | 다른 제품의 브랜치가 무거운 까닭(스키마 통째 복제, 손 재배치)을 피한다 |
| 통째로 버전, 브랜치 하나, 검토 없음 (T0166) | 항목 단위 버전, 브랜치 여럿, 다른 사람의 승인 (12) | 여러 조직이 동시에 고친다. 어떤 변경이든 새 버전이 되는 것도 피한다 |
| 엑셀 양식, 격자 안 읽음 (T0152, T0164) | 그대로 (13) | 파서 포트, 크기 상한, 수식은 값으로만을 더했다 |
| 주기 셋, 기록 하나에 단계별 수와 시간 (T0151) | 그대로 (14) | 최소 간격 15분과 기록 90일은 재지 않은 숫자라 가져오지 않았다 |
| ECMP는 장비 설정 값에서, 경로표는 받지 않음 (T0164) | 그대로 | 경로표는 구성이 아니라 상태다 |

조사의 한계는 이렇다. 여러 제품의 안쪽 동작과 부하 특성은 확인하지 못했다. 정제 연산의 수와 안전장치의 숫자는 추정이고 견본 시험과 알파에서 고친다. 프리셋이 본뜰 소스 API의 모양은 실제 제품 문서와 대조한 적이 없다.

## 버린 길
- **소스 제품마다 전용 커넥터 코드**: 코드가 소스 수만큼 늘고, 의미를 맞추는 일은 코드가 풀지 못한다.
- **사용자 코드(스크립트) 허용**: 같은 입력이면 같은 결과, 안전, 감사의 약속이 깨진다.
- **기존 수집 엔진을 들이기**: 조사한 것들은 라이선스가 허용 목록 밖이다.
- **질의할 때 소스에 물어 오기(연합)**: 소스에 부하를 주고 버전을 고정할 수 없다.
- **이번에 안 본 것은 쓸어 지우기**: 덜 받은 수집에서 오삭제가 난다.
- **값마다 출처 저장하기**: 규모를 감당하지 못한다.
