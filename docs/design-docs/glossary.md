# 용어집

## 쓰는 법

1. **일하면서 실제로 쓰는 말을 쓴다.** 말을 지어내지 않는다. 현업에서 쓰는 말이 있으면 그것을 쓴다.
2. **한 가지 뜻에 한 가지 말.** 같은 것을 화면마다 다르게 부르지 않는다. 말을 바꾸면 옛 말을 `harness/config/ui-words.yaml`에 넣어 돌아오지 못하게 한다(`WORD001`).
3. **사람에게 보이는 글은 해요체의 쉬운 말.** 버튼은 다음에 일어날 일을 말하고, 숫자에는 단위를 붙인다. 화면은 다른 저장소가 만들고, API는 글이 아니라 코드와 값을 준다(ADR-0016).
4. **타입의 이름은 영어다.** 객체 타입, 링크 타입, 액션 타입, 속성의 이름은 영어로 짓는다(ADR-0007). 화면에서 한국어로 보일 이름은 데이터로 따로 둔다.

## 모델의 말

| 쓰는 말 | 쓰지 않는 말 | 뜻 |
|---|---|---|
| **객체** / **객체 타입** | 개체, 엔티티 | 세계에 있는 것 하나(서버, VM, 스위치) / 그 종류 |
| **링크** / **링크 타입** | 관계, 선 | 객체 사이를 잇는 것 / 그 종류 |
| **사실** / **가정** / **모름** | 추정, 확인됨, N/A | 값과 링크의 근거 등급 (코드와 데이터의 값은 `fact`, `assumed`, `unknown`) |
| **세계 스냅샷** | 덤프, 익스포트 파일 | KG의 한 범위를 담은 파일(내보내기). 프락시움이 공개된 형식으로 내보낸다 |
| **번** | 회, 횟수 | 세는 말 ("3번") |

## 프락시움의 말

테라리움의 "운영"(실험 종류의 이름)과 여기의 "운영 세계"는 다른 뜻이다.

### KG와 모델

| 쓰는 말 | 쓰지 않는 말 | 뜻 |
|---|---|---|
| **운영 세계** | 프로덕션 세계, 디지털 트윈 | 현실의 데이터로 지은 세계. KG가 그 실체다 |
| **KG** | 토폴로지, 온톨로지(데이터를 가리킬 때) | 현실의 IT 인프라를 객체와 링크로 적은 지식 그래프 |
| **KG 버전** | 스냅샷(KG를 가리킬 때) | 변경의 이어짐 위에 붙인 봉한 이름. 바뀌지 않는다. 차이와 감사는 봉한 버전 사이에서 한다 |
| **변경 묶음** | | KG에 한꺼번에 적용되는 변경들. 적용할 때마다 번호(`change_seq`)가 하나씩 오른다 |
| **표준 모델** | 기본 스키마 | 제품에 들어 있는 객체 타입·링크 타입·액션 타입의 목록. 층 아홉에 걸친다 |
| **링크의 뜻** | 관계 종류 | 링크 타입마다 닫힌 목록(열한 가지)에서 하나 고르는 의미. 영향이 어떻게 번지는지를 정한다 |
| **채널** | | 객체의 상태를 가르는 닫힌 여섯: `service`, `power`, `cooling`, `network`, `storage`, `management`. 채널마다 `up`, `down`, `unknown` |
| **이중화 묶음** | 리던던시 그룹 | 구성원 중 몇 개가 살아야 하는지(`min_alive`)를 가진 객체 |
| **근거의 종류** | | 값이 어디서 왔는지의 닫힌 넷: 설정에서 읽음, 받은 순간에 그렇게 보임, 사람이나 문서가 적음, 규칙이 끌어냄. 근거 등급과는 다른 축이다 |
| **식별 키** | 유니크 키 | 객체가 같은 것임을 알아보는 속성이나 바깥 식별자의 묶음 |
| **값 타입** | | 속성의 자료형에 붙는 이름(IPv4 주소, 일련번호 등). 검사와 다듬기를 가진다 |

### 받기

| 쓰는 말 | 쓰지 않는 말 | 뜻 |
|---|---|---|
| **소스** | 원천, 데이터 소스 | 데이터를 읽어 오는 현실 시스템이나 파일 |
| **어댑터** | 커넥터(코드를 가리킬 때) | 프로토콜 하나를 말할 줄 아는, 제품에 들어 있는 코드 |
| **프리셋** | 템플릿, 레시피 | 소스 제품 하나에 맞춘 데이터: 허용된 요청의 목록과 기본 매핑 |
| **원본 기록** | 로우 데이터 | 소스에서 받은 그대로 보관한 기록 한 줄 |
| **데이터셋** | 테이블 | 원본 기록을 행과 컬럼으로 본 표, 그리고 정제의 결과 |
| **정제** | 전처리, 변환 | 닫힌 목록의 연산으로 데이터셋을 다듬는 일 |
| **공급** | | 데이터셋 하나에서 객체 타입 하나로 가는 매핑 하나. 자기가 매핑한 속성만 쥔다 |
| **매핑** | 대응 | 데이터셋의 컬럼을 객체 타입의 속성에 잇는 정의 |
| **링크 정의** | 관계 규칙 | 객체 사이를 잇는 조건을 적은 정의 |
| **기대 조건** | | 데이터셋과 공급에 붙이는 닫힌 종류의 데이터 검사. 어기면 멈추거나(`fail`) 문제 목록에 올린다(`warn`) |
| **동기화** | 싱크 | 소스에서 받아 KG의 새 버전까지 가는 실행 한 번 |
| **수집 봉투** | 인제스트 포맷 | 제품 밖의 수집기가 원본 기록을 프락시움에 보낼 때 쓰는 공개된 모양 |
| **수집기** | | 소스를 읽어 원본 기록을 본체로 보내는 역할. 소스가 있는 망에 따로 띄우거나, 소스의 담당자가 수집 봉투로 직접 만든다 |
| **안전장치** | 가드 | 적용 전에 멈추게 하는 검사 |
| **붙잡힌 흐름** | | 안전장치가 걸려 적용만 멈춘 흐름. 받는 것은 멈추지 않고, 운영 역할이 풀거나 버린다 |
| **적용** | 퍼블리시 | 후보를 KG의 새 버전으로 공개하는 일 |

### 정의의 버전과 브랜치

| 쓰는 말 | 쓰지 않는 말 | 뜻 |
|---|---|---|
| **정의** | 설정, 컨피그 | 버전이 있는 모든 설정: 타입, 소스, 프리셋, 정제, 공급, 식별 규칙, 링크 정의, 기대 조건, 일정, 안전장치의 값 |
| **정의 묶음** | | 어느 항목이 어느 판인가의 전체 목록. 내용 해시를 가지고 `D-142`처럼 번호로 부른다 |
| **자리** | | 정의의 항목이 딸린 곳(소스, 객체 타입, 출발 타입 등). 고치는 권한과 승인의 범위를 가르는 기준이다 |
| **브랜치** | 변경안 | 운영에 영향 없이 정의를 고쳐 보는 작업 공간. 여럿이 동시에 열 수 있다 |
| **제안** | | 브랜치를 운영의 정의에 들여 달라는 요청 |
| **병합** | 머지 | 제안을 검사와 승인을 거쳐 운영의 정의로 한꺼번에 들이는 일 |
| **막는 까닭** | | 제안이 병합되지 못하는 까닭(충돌, 낡음, 검사 실패, 모자란 승인 등). 상태가 아니라 그때그때 끌어낸다 |
| **옮김** | 마이그레이션 | 깨는 변경에 함께 적는 것: 어느 속성이 어느 속성으로, 어떤 바꾸기로 가는지와 식별 이력의 처리 |
| **후보 실행** | 드라이런 | 받아 둔 원본 기록과 브랜치의 정의로 후보 KG를 만들어 지금 버전과의 차이를 보는 일. 운영에 영향이 없다 |
| **시험 수집** | | 새 소스를 더하는 브랜치에서 하는 읽기 전용 수집. 브랜치에 딸린 자리에 담긴다 |

### 질의와 운영

| 쓰는 말 | 쓰지 않는 말 | 뜻 |
|---|---|---|
| **영향 범위** | 블라스트 레이디어스 | 어떤 객체가 죽었을 때 죽거나 위험해지는 객체들 |
| **투영** | 프로젝션 | KG 버전 하나에서 만든, 영향 범위 계산용 메모리 안의 그래프. 다시 만들 수 있다 |
| **변경 알림** | 이벤트, 웹훅 | KG의 새 버전에서 바뀐 것을 다른 시스템에 알리는 길 |
| **신선도** | | 그 데이터를 마지막으로 온전히 받은 때로부터 지난 시간 |
| **문제 목록** | 에러 리스트 | 받는 중에 풀지 못한 것(충돌, 못 이은 링크, 틀린 값)과 알림의 목록. 규칙으로 푼다 |
| **건강** | | 소스, 공급, 타입 같은 자원이 지금 제대로 도는지: `healthy`, `degraded`, `failing`, `paused`, `unknown` |
| **목표** | | 공급, 타입, 속성에 붙이는 약속(신선도, 온전함, 유효성, 받는 양). 못 지킨 비율을 센다 |
| **역량 질문** | | 이 KG가 답할 수 있어야 하는 물음. 닫힌 패턴으로 적는 정의다 |
| **충족률** | | 역량 질문이 요구하는 것을 다 채운 대상 객체의 수 ÷ 대상 객체의 수 |

### 프락시움 자신의 운영

| 쓰는 말 | 쓰지 않는 말 | 뜻 |
|---|---|---|
| **사건 코드** | 로그 번호 | 로그와 오류와 알림에 붙는 안정된 코드. 뜻, 심각도, 살펴볼 것, 할 수 있는 운영 행위가 딸린다 |
| **운영 행위** | | 프락시움을 돌보려고 API로 하는, 정해진 목록의 일(소스 멈추기, 일꾼 비우기 등) |
| **진단** | | 지금 무엇이 아프고, 까닭이 무엇이고, 근거 신호와 할 수 있는 운영 행위가 무엇인지의 구조가 있는 답(`diagnose`) |
| **점검 모드** | 유지보수 모드 | 고치는 일을 받지 않고 읽기만 답하는 상태 |

### 비밀 값, 정의를 쓰는 에이전트, 임시 콘솔

| 쓰는 말 | 쓰지 않는 말 | 뜻 |
|---|---|---|
| **비밀 값** | 크리덴셜, 패스워드 | 소스의 연동 정보(계정, 토큰, 인증서, 연결 문자열) 같은 것. 쓰기만 되고 정의에는 참조만 들어간다 |
| **으뜸 열쇠** | 마스터 키 | 데이터 열쇠를 감싸는 열쇠. 저장소 밖에 둔다 |
| **봉투 암호화** | | 비밀 값마다 데이터 열쇠로 암호화하고 데이터 열쇠를 으뜸 열쇠로 감싸는 방식 |
| **위험의 등급** | | 제안의 후보 차이에서 계산하는 R0~R3. R3는 언제나 사람이 본다 |
| **자동 병합** | | 정책이 허락한 낮은 등급의 병합. 승인이 아니다. 기본은 꺼짐 |
| **지정해서 다시 받기** | 새로고침 | 객체를 지정해 그 객체의 것만 소스에서 지금 다시 읽는 일 |
| **기대와 견주기** | | 기대하는 값과 기준 시각으로 소스에서 본 값을 견주는 일. 넷: `confirmed`, `not_yet`, `contradicted`, `unverifiable` |
| **해석기**, **줄 틀** | 파서 | 문서를 나무로 만드는 제품에 든 닫힌 목록 / 정해진 꼴의 글을 줄로 읽는 데이터 |
| **모양 카드** | | KG의 연결 수의 분포, 깊이, 묶음의 크기, 사이트 건넘의 비율. 지어낸 세계 생성기를 맞추는 데 쓴다 |
| **시스템 KG** | | 프락시움 자신의 부품을 담는 따로 된 KG(이름 공간 `sys`) |
| **임시 콘솔** | 화면, UI | 클로즈 베타까지 기능을 눌러 보는, 지울 수 있는 시험용 화면. 제품의 화면이 아니다 |

### 권한

| 쓰는 말 | 쓰지 않는 말 | 뜻 |
|---|---|---|
| **권한 부여** | | 누구(사람이나 무리) × 역할 × 범위 하나. 권한은 여기서만 온다 |
| **역할** | | 제품에 든 닫힌 일곱: `viewer`, `editor`, `approver`, `operator`, `model_steward`, `auditor`, `admin` |
| **범위** | | 권한 부여가 닿는 곳. 전체, 객체 타입(층, 이름 공간), 소스, 민감 등급의 한도 |
| **담당자** | 주인 | 소스, 타입, 정의의 항목에 붙는 사람이나 무리. 권한이 아니라 연락처다 |

## 쓰지 않는 말

| 쓰지 않는 말 | 대신 | 까닭 |
|---|---|---|
| 토폴로지 | KG | 제품 책임자가 정했다. 표준의 이름에 든 것만 그대로 쓴다 |
| 도메인(권한이나 주인의 단위로) | 범위, 담당자 | 무엇의 단위인지 모호하다(ADR-0012) |
| 주인 도메인, 도메인 주인 | 담당자 | 주인이 아니라 연락처다 |
| 플랫폼 관리자 | 관리자(`admin`) | 역할은 제품에 든 일곱뿐이다 |
| 가린 도메인 | 읽기 범위에서 뺀다 | 도메인이라는 개념이 없다 |
| 스냅샷(KG를 가리킬 때) | KG 버전 | 버전은 변경의 이어짐 위의 봉한 자리다 |
