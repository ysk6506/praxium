# 용어집

## 쓰는 법

1. **일하면서 실제로 쓰는 말을 쓴다.** 말을 지어내지 않는다. 현업에서 쓰는 말이 있으면 그것을 쓴다.
2. **한 가지 뜻에 한 가지 말.** 같은 것을 화면마다 다르게 부르지 않는다. 말을 바꾸면 옛 말을 `harness/config/ui-words.yaml`에 넣어 돌아오지 못하게 한다(`WORD001`).
3. **사람에게 보이는 글은 해요체의 쉬운 말.** 버튼은 다음에 일어날 일을 말하고, 숫자에는 단위를 붙인다.
4. **테라리움과 같은 것은 같은 말로 부른다.** 두 제품을 오가는 사람이 다시 배우지 않게 한다.

## 테라리움과 함께 쓰는 말

| 쓰는 말 | 쓰지 않는 말 | 뜻 |
|---|---|---|
| **객체** / **객체 타입** | 개체, 엔티티 | 세계에 있는 것 하나(서버, VM, 스위치) / 그 종류 |
| **링크** / **링크 타입** | 관계, 선 | 객체 사이를 잇는 것 / 그 종류 |
| **사실** / **가정** / **모름** | 추정, 확인됨, N/A | 값과 링크의 근거 등급 |
| **세계 스냅샷** | 덤프, 익스포트 파일 | 모델로 적은 세계 하나를 담은 파일. 프락시움이 내주고 테라리움이 받아 연다 |
| **판정 기록** | 인증서, 리포트 | 실험의 결과를 밖에서 쓰도록 내준 파일. 테라리움이 내주고 프락시움이 받는다 |
| **번** | 회, 횟수 | 세는 말 ("3번") |

## 프락시움의 말 (초안)

제품 목표가 굳고 설계를 다시 본 뒤에 정해요. 지금 정해진 것은 이것뿐이에요.

| 쓰는 말 | 쓰지 않는 말 | 뜻 |
|---|---|---|
| **운영 세계** | 프로덕션 세계, 디지털 트윈 | 현실의 데이터로 지은 세계 |
| **소스** | 원천, 데이터 소스 | 데이터를 읽어 오는 현실 시스템이나 파일 |
