# 일반 용어집

[용어집](glossary.md)의 쓰는 법을 따르는 표다. 제품 고유의 말이 아니라 개발과 운영에서 널리 쓰는 말을 정한다. 문서 용어 검사는 이 표의 "옛 표기" 열도 읽는다(ADR-0029).

### API와 계약
| 표준 용어 | 옛 표기(쓰지 않음) | 뜻 | 영어 대응 |
|---|---|---|---|
| **경로 (API 경로)** | 길 이름, 길 등록부, 길 목록, 자원과 길, 기능마다의 길, 기능의 길, 닿는 길 | 요청이 가는 주소의 형태(`/v1/...`)와 그래프에서 따라가는 경로 | route / path |
| **처리 경로** | 쓰는 길, 읽는 길, 고치는 길, 보내는 길, 보는 길, 넣는 길, 돕는 길, 푸는 길, 바꾸는 길 | 코드나 데이터가 지나가는 경로(쓰기 경로, 읽기 경로) | path |
| **버린 대안** | 버린 길 | 검토하고 채택하지 않은 대안 | rejected alternative |
| **필드** | 입력 칸, 출력 칸, 선택 칸, 일정 칸, 역할 칸, 작업 칸, 설계 칸, 길과 칸, 칸마다, 칸별 | 요청, 정의, 레코드를 이루는 항목 하나. 표의 열은 컬럼 | field |
| **페이지네이션** | 쪽 넘김 | 목록을 나눠 돌려주는 방식 | pagination |
| **엔벨로프** | 응답 봉투, 답의 봉투 | 응답이나 수집 데이터를 감싸는 공통 구조(`as_of`, 신선도 표지 등) | envelope |
| **토큰** | 증표 | 인증에 쓰는 토큰 | token |
| **멱등성 보장** | 겹침 방지 | 같은 요청이 겹쳐 들어와도 한 번만 처리되게 하는 것(`Idempotency-Key`) | idempotency |
| **낙관적 동시성 제어** | 동시 수정 막기 | 읽은 버전이 바뀌었으면 쓰기를 거부하는 방식(`If-Match`) | optimistic concurrency control |
| **메이저 버전** | 큰 버전 | 호환되지 않는 변경이 들어가는 버전 | major version |
| **호환성을 깨는 변경** | 깨는 변경 | 기존 사용자를 깨뜨릴 수 있는 계약 변경(`breaking_change`) | breaking change |
| **문제 상세 본문** | 문제 본문 | RFC 9457의 오류 응답 본문 | problem details body |
| **고정 목록** | 닫힌 목록 | 제품에 정해져 있어 사용자가 늘릴 수 없는 목록(열거형) | fixed list / enum |
| **사전 정의 질의** | 닫힌 질의 | KG에 묻는, 제품에 정해진 13종의 질의. 처음 나올 때 "사전 정의 질의(closed queries)"로 영어를 병기한다 | predefined query (closed queries) |
| **CLI** | 명령줄 클라이언트 | 명령줄로 API를 부르는 클라이언트 | CLI |
| **트레이스 ID** | 추적 번호 | 한 요청을 따라가는 식별자 | trace ID |
| **타임라인** | 시간줄 | 자원마다 시간순으로 보는 이력 | timeline |
| **인터페이스** | MCP 면, 읽는 면 | MCP 같은 접점 | interface |
| **푸시 수집** | 밀어 넣기 | 소스나 수집기가 데이터를 본체로 보내는 수집 방식 | push ingestion |

### 저장과 버전
| 표준 용어 | 옛 표기(쓰지 않음) | 뜻 | 영어 대응 |
|---|---|---|---|
| **확정** | 봉인, 봉하기, 봉한 | 결정 기록(ADR)이나 KG 버전을 더는 바꿀 수 없게 굳히는 일 | seal |
| **적재** | 처음 싣기, 싣기 | 대량으로 데이터를 넣는 일 | load (initial load) |
| **그룹 (자산)** | 자산 묶음 | 자산을 묶은 그룹 | group |
| **ECMP 그룹** | ECMP 묶음 | 같은 비용으로 갈라지는 경로의 모음 | ECMP group |
| **규칙 세트** | 규칙 묶음 | 규칙을 모은 한 벌 | rule set |
| **스테이징 영역** | 임시 자리 | 적용 전에 변경을 담아 차이를 보는 임시 영역 | staging area |
| **콜드 스토리지** | 오래된 것의 자리 | 오래된 데이터를 두는 저렴한 저장 계층 | cold storage |
| **단일 진실 공급원** | 진실의 자리 | 같은 사실을 한 곳에서만 정본으로 두는 원칙(SSOT) | single source of truth |
| **플레이스홀더** | 자리 표시 | 값이 들어갈 자리를 표시하는 이름 | placeholder |
| **리스** | 점유 | 한 시점에 한 실행기만 일하게 하는 기한 있는 소유권 | lease |
| **수집 변경 로그** | 받은 변경의 기록 | 소스에서 받은 변경을 받은 그대로 쌓는 로그 | ingest change log |
| **수집 순서** | 받은 차례, 차례 굳히기 | 받은 변경에 번호를 매겨 정하는 순서 | ingest order / sequencing |
| **오버레이** | 덧씌움 | 표준 타입 위에 조직이 재정의를 얹는 계층 | overlay |
| **스키마 변경** | 모양의 바뀜, 모양 바뀜 | 소스가 보내는 스키마가 바뀌는 것 | schema change |
| **스키마 초안** | 표의 스케치 | 테이블 설계 초안 | schema draft |
| **컬럼형** | 열 단위 파일 | 열 단위로 저장하는 파일 형식 | columnar |
| **삭제** | 지움, 지우기 | 데이터를 없애는 일. 보존 기한이 지난 뒤의 삭제는 purge | delete / purge |
| **복원** | 되살리기 | 폐기한 것을 다시 쓸 수 있게 되돌리는 일 | restore |
| **아카이브** | 내려 두기 | 오래된 데이터를 콜드 스토리지로 옮기는 일 | archive |
| **쓰기 감소** | 쓰기 줄이기 | 같은 키의 쓰기를 합쳐 쓰기 수를 줄이는 일 | write coalescing |
| **보존 기한** | 보관 기한 | 데이터를 남겨 두는 기한 | retention |
| **쓰기 부하** | 쓰기의 세기 | 쓰기가 몰리는 정도 | write load |
| **파티션 키** | 나눔의 열쇠 | 데이터를 나누는 기준 키 | partition key |
| **가상의 예시** | 지어낸 예시 | 문서에서 보이려고 만든 가상의 값과 예 | fictional example |
| **증분 갱신** | 늘어난 만큼만 | 바뀐 부분만 갱신하는 방식 | incremental update |

### 수집 파이프라인
| 표준 용어 | 옛 표기(쓰지 않음) | 뜻 | 영어 대응 |
|---|---|---|---|
| **수집** | 소스 받기, 받기 | 소스에서 데이터를 가져와 원본 레코드로 쌓는 일 | ingestion |
| **정합성 대조** | 소스와 맞추기, 맞추기의 주기, 정합 대조 | 스트림과 전체 스냅샷을 견주어 어긋남을 찾는 일 | reconciliation |
| **건수 대조** | 수 맞춤 | 단계마다 들어온 건수와 나간 건수를 견주어 빠진 것을 찾는 일 | count reconciliation |
| **소스 보호** | 소스 지키기 | 소스에 거는 호출 제한, 타임아웃, 서킷 브레이커 | source protection |
| **중복 제거 기간** | 겹침을 거르는 기간 | 같은 건을 중복으로 보고 버리는 기간(`dedupe_window`) | dedupe window |
| **지연 도착 값 처리** | 늦은 값 막기, 늦은 값 보호 | 늦게 오거나 순서가 뒤바뀐 값을 다루는 방법 | out-of-order handling |
| **소스 탐색** | 들여다보기 | 소스를 읽기만 해서 구조를 알아보는 일 | introspection |
| **파싱** | 읽어 들이기 | 문서를 트리로, 트리를 행으로 만드는 일 | parsing |
| **트리** | 나무 | 계층 구조 | tree |
| **감사 로그** | 감사 기록 | 누가 무엇을 했는지 남기는 로그 | audit log |
| **호출 이력** | 호출 기록 | 호출한 내역 | call history |
| **병합 / 분리 (식별)** | 가르기 | 같은 객체로 합치거나 다른 객체로 나누는 식별 변경 | identity merge / split |
| **식별** | 같은 것 알아보기 | 서로 다른 소스의 데이터가 같은 객체인지 알아보는 일 | identity resolution |
| **시드** | 씨앗 | 생성기의 난수 시드 | seed |
| **합성** | 지어낸 세계, 지어낸 데이터, 지어낸 견본 | 생성기가 만든 세계와 데이터는 합성, 문서의 예시는 가상 | synthetic |
| **샘플** | 견본 | 예시 데이터. 테스트에 쓰면 픽스처 | sample / fixture |
| **백필** | 뒤채움 | 과거 구간의 데이터를 나중에 채우는 일 | backfill |
| **워커** | 일꾼 | 작업을 실행하는 프로세스 | worker |
| **임계값** | 문턱 | 넘으면 동작이 바뀌는 기준값 | threshold |

### 정의와 브랜치 (일반)
| 표준 용어 | 옛 표기(쓰지 않음) | 뜻 | 영어 대응 |
|---|---|---|---|
| **메인 브랜치** | 본줄기 | 운영 정의의 기준이 되는 브랜치(`main`) | main branch |
| **리버트** | 되돌리기 | 새 변경으로 이전 변경을 취소하는 일. 상태를 이전 시점으로 되감는 롤백과 구분한다. 이 제품은 KG를 되감지 않는다 | revert |
| **긴급 리버트** | 급한 되돌리기 | 승인 없이 먼저 취소하고 사후에 검토하는 리버트 | emergency revert |
| **3-way 비교** | 세 쪽 견주기 | 공통 조상과 양쪽 변경을 견주는 병합 방식 | 3-way merge |
| **병합 큐** | 병합의 줄 | 병합을 한 줄로 세우는 큐 | merge queue |
| **위임** | 맡김, 맡긴다, 맡기고, 맡기는 | 일을 에이전트에게 넘겨 수행하게 하는 것 | delegation |
| **서킷 브레이커** | 회로 차단 | 실패가 이어지면 호출을 끊는 장치 | circuit breaker |
| **당직** | 당번 | 장애 때 연락받는 사람(on-call) | on-call |
| **클로즈드 베타** | 클로즈 베타, 클베 | 제한된 사용자에게 여는 테스트 단계 | closed beta |
| **오픈 베타** | 오베 | 모두에게 여는 테스트 단계 | open beta |

### 권한과 보안
| 표준 용어 | 옛 표기(쓰지 않음) | 뜻 | 영어 대응 |
|---|---|---|---|
| **키** | 열쇠 | 암호화, 조인, 파티션, 락, 해시에 쓰는 키 | key |
| **데이터 키** | 데이터 열쇠 | 시크릿을 암호화하는 키(DEK) | data encryption key |
| **키 관리 서비스** | 열쇠 관리 서비스 | 키를 보관하고 래핑하는 서비스(KMS) | key management service |
| **로테이션** | 돌려 쓰기 | 키나 시크릿을 새것으로 교체하는 일 | rotation |
| **복호화** | 비밀 값 풀기 | 암호화한 값을 원래대로 푸는 일 | decrypt / unwrap |
| **쓰기 전용** | 쓰기만 되는 값 | 쓸 수만 있고 읽을 수 없는 값 | write-only |
| **저장 데이터 / 전송 구간** | 쉬는 데이터, 지나가는 길 | 저장돼 있는 데이터(data at rest)와 전송 중인 구간(data in transit) | data at rest / in transit |
| **분리망** | 떨어진 망 | 외부와 격리된 망 | air-gapped network |
| **필터링** | 거르기, 거름 | 권한이나 조건으로 걸러 내는 일 | filtering |
| **그룹** | 무리 | 사용자나 자원의 모음 | group |
| **회수** | 거두다, 거둔, 거두는 | 부여한 권한이나 토큰을 되찾는 일 | revoke |
| **캐시** | 권한 사본 | 권한 정보를 임시로 복사해 둔 것 | cache |
| **서비스 계정** | 시스템 계정 | 에이전트나 기계 호출자가 쓰는 계정 | service account |

### 관측성과 운영
| 표준 용어 | 옛 표기(쓰지 않음) | 뜻 | 영어 대응 |
|---|---|---|---|
| **근본 원인** | 뿌리 까닭 | 여러 이상의 공통 원인 | root cause |
| **이상 탐지** | 평소와 다름 | 평소와 다른 값을 찾는 일 | anomaly detection |
| **하트비트** | 생존 신호 | 살아 있음을 알리는 주기 신호 | heartbeat |
| **지연** | 밀림 | 처리가 뒤처진 정도(lag)와 쌓인 양(backlog) | lag / backlog |
| **카디널리티** | 가짓수 | 값의 종류 수 | cardinality |
| **다운샘플링** | 뭉쳐 줄이기, 뭉쳐 줄인다 | 오래된 데이터를 성기게 줄이는 일 | downsampling |
| **측정** | 재서, 잰 값, 재지 않 | 값을 재는 일 | measure |
| **미리 실행** | 미리 해 보기 | 운영 액션을 실제로 하지 않고 결과만 미리 보는 일 | dry run (operation) |
| **교체** | 갈아 끼움, 갈아 끼우기 | 새것으로 바꾸는 일(롤링 교체) | swap / rolling replace |
| **스누즈** | 잠시 끔 | 알림을 일정 시간 미루는 것 | snooze |
| **알림 채널** | 알림 길 | 알림을 보내는 경로 | notification channel |
| **상태 전이** | 상태의 흐름, 상태 흐름 | 상태가 바뀌는 순서 | lifecycle |
| **이상 상태** | 아픈, 아프면 | 정상이 아닌 상태. 몸에 빗대어 쓰지 않는다 | unhealthy |

### 질의와 영향 범위
| 표준 용어 | 옛 표기(쓰지 않음) | 뜻 | 영어 대응 |
|---|---|---|---|
| **의존** | 기댐 | 어떤 것이 다른 것에 의존하는 관계 | dependency |
| **전파** | 번짐 | 장애나 영향이 다른 객체로 번지는 일 | propagation |
| **앵커** | 닻 | 영향 범위 계산이 출발하는 기준 노드 | anchor |
| **순회** | 걷기 | 그래프를 따라 방문하는 일 | traversal |

| **가정 포함 응답** | 가정을 넣은 답 | 가정을 포함해 계산한 응답 | answer with assumptions |

### 개발 과정과 하네스
| 표준 용어 | 옛 표기(쓰지 않음) | 뜻 | 영어 대응 |
|---|---|---|---|
| **테스트** | 시험 | 코드나 정의가 맞는지 확인하는 일과 그 코드 | test |
| **프로토타입** | 시제품 | 가능성을 확인하려고 만든 임시 구현 | prototype |

## 뜻이 갈리는 말

아래 말은 뜻이 여럿이라 옛 표기 열에 적지 않는다. 문서를 고칠 때 문맥을 읽고 뜻마다 표준 용어로 바꾼다. 이 표는 검사가 읽지 않는다.

| 옛 표기 | 문맥 | 표준 용어 |
|---|---|---|
| 길 | API 경로 / 처리 경로(쓰기 경로, 읽기 경로)·방식 / 버린 대안 / 도달 경로 / 알림 채널 | 경로, 방식, 대안, 채널 중 맞는 것 |
| 묶음 | 변경 배치 / 이중화 그룹 / 정의 세트 / 규칙 세트 / 자산 그룹 / 배치 / ECMP·LAG 번들 | 뜻마다 다른 용어를 쓴다 |
| 자리 | 스테이징 영역 / 읽기 워터마크 / 소스 커서 / 콜드 스토리지 / 단일 진실 공급원 / 플레이스홀더 / 사이트 / 지점 | 뜻마다 다른 용어를 쓴다 |
| 칸 | 필드(API, 정의) / 컬럼(DB) / 열 / 항목 | 필드, 컬럼, 열 중 맞는 것 |
| 쪽 | 청크 / 측(읽기 측, 호출 측) / 호출자, 소비자, 발신자 | 페이지는 페이지네이션 |
| 뜻 | 의미 / 링크 의미(semantics) / 표 머리글은 설명 | 의미, 설명 |
| 열쇠 | 키(암호 키, 조인 키, 파티션 키, 락 키, 해시 키) | 키 |
| 줄 | 행(row) / 라인 / 레코드 / 큐(병합 큐) | 행, 라인, 레코드 중 맞는 것 |
| 판 | 버전 / 리비전 | 버전 |
| 흐름 | 스트림 / 파이프라인 / 플로우 / 시퀀스 | 맥락에 맞는 것 |
| 걸음 | 홉(그래프) / 단계(처리) | 홉, 단계 |
| 닿다 | 접속하다·접근하다 / 도달 가능한·영향받는 | 접속, 도달, 영향 |
| 물러나다 | 폐기(retired) 처리 / 삭제 처리 / 지원 중단 / 폴백 | 뜻마다 다른 용어 |
| 풀기 / 풀다 | 해제(release) / 복호화 / 해결 | 뜻마다 다른 용어 |
| 차례 | 순서 / 절차 | 순서, 절차 |
| 짝 | 쌍 / 조합 / 피어 | 맥락에 맞는 것 |
| 갈래 | 분류 / 분기 수(fan-out) / 경우 | 맥락에 맞는 것 |
| 모양 | 스키마 / 형식 / 형태 | 맥락에 맞는 것 |
| 기록 | 감사 로그 / 접근 로그 / 호출 이력 / 실행 이력 / 메시지 로그 | 맥락에 맞는 것 |
| 단위 (아키텍처) | 유닛(구조 검사 용어는 단위를 유지할 수 있다) | 시간 단위 같은 일반 용법은 그대로 |
| 저장소 | Git 저장소는 리포지토리, 데이터를 두는 곳은 스토리지 | 맥락에 맞는 것 |
| 사건 | 데이터와 로그는 이벤트, 장애는 인시던트 | 이벤트, 인시던트 |
| 되돌리다 (동사) | 리버트하다(새 변경으로 취소), 롤백하다(상태를 이전 시점으로 되감기) | 리버트, 롤백 |
